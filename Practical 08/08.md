# Experiment 8: Analysis of Server Event and Security Logs

**Aim:** To analyze Windows Security logs using Windows Event Viewer (`eventvwr.msc`) to identify security anomalies, successful/failed logons, and special privilege assignments[cite: 54].

## Workflow & Commands
1. Open Event Viewer via Run dialog:
   ```cmd
   eventvwr.msc
   ```
2. Navigate to Windows Logs -> Security.
3. Filter logs by key Event IDs:
  - 4624: Successful Logon
  - 4625: Failed Logon Attempt
  - 4634: Logoff Event
  - 4672: Special Privilege Assignment
  - 4648: Explicit Credential Logon
