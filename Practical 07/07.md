# Experiment 7: Windows Security Configuration and Access Audit

**Aim:** To audit Windows system configuration, user accounts, Group Policy settings, PowerShell execution policies, and directory permissions using Windows tools and Sysinternals AccessChk[cite: 45].

## Workflow & Commands
1. **System & User Audit:**
   ```cmd
   winver
   whoami /groups
   net user
   net localgroup Administrators
   ```
2. **Group Policy & Execution Policy:**
   ```bash
   gpresult /r
   gpresult /scope computer /r
   Get-ExecutionPolicy -List
   ```
3. **Directory Permissions:**
   ```bash
   accesschk.exe -d -v "%USERNAME%" "C:\Users\%USERNAME%"
   ```
