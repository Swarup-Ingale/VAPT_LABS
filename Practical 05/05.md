# Experiment 5: Evaluation of Database Credential Strength and Password Hash Security Using Hashcat

**Aim:** To evaluate database credential strength using MySQL 8.0.46 validate_password component and perform dictionary-based password recovery on a SHA-256 hash using Hashcat 7.1.2[cite: 32].

## Workflow & Commands
1. **MySQL Audit & Policy Configuration:**
   ```sql
   SELECT VERSION();
   SELECT User, Host, plugin FROM mysql.user;
   INSTALL COMPONENT 'file://component_validate_password';
   SHOW VARIABLES LIKE 'validate_password%';
   ```
2. **Hash Generation & Hashcat Attack:**
   ```bash
   "password123" | Set-Content -NoNewline .\password.txt
    $hash = (Get-FileHash .\password.txt -Algorithm SHA256).Hash
    $hash | Set-Content -NoNewline .\test_hash.txt
    .\hashcat.exe -m 1400 -a 0 .\test_hash.txt .\words.txt
    .\hashcat.exe -m 1400 .\test_hash.txt --show
   ```
