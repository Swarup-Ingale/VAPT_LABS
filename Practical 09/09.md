# Experiment 9: Software License Compliance Audit and Network Vulnerability Scanning

**Aim:** To audit system software information using WinAudit and identify open ports, services, and potential vulnerabilities using Nmap Vulnerability Engine.

## Workflow & Commands
1. **Software Compliance Audit:** Open WinAudit and examine **System Overview** and **Installed Software / Active Setup** categories.
2. **Network Vulnerability Scanning via Nmap:**
   ```cmd
   nmap --version
   nmap --script vuln 127.0.0.1
   nmap -sV --script vuln -p 1-1024 127.0.0.1
   ```
