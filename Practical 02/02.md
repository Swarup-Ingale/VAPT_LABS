# Experiment 2: Network Scanning & Enumeration

**Aim:** To sweep a live subnet for active hosts, enumerate exposed ports, fingerprint services and OS versions, and map the attack surface[cite: 64].

## Workflow & Commands
1. **Host Discovery (Ping Sweep):**
   ```bash
   nmap -sn 10.10.30.0/24
   ```
2. **Port Scanning:**
   ```bash
   nmap -p- -T4 10.10.30.20
   ```
3. **Service & Version Detection:**
   ```bash
   nmap -sV 10.10.30.20
   ```
4. **OS Fingerprinting & Aggressive Scan:**
   ```bash
   nmap -O 10.10.30.20
   nmap -A 10.10.30.20
   ```
