# Experiment 1: Identification of Information Exposure Risks through Social Media and Internet Sources

**Aim:** To understand Human Security Assessment by identifying how sensitive information can be exposed through social media, public websites, internet sources, and human interactions, and evaluating phishing awareness and email authentication[cite: 68].

## Workflow & Commands
1. **Visibility Audit (Passive Reconnaissance):**
   * Access OSINT Framework and query WHOIS records[cite: 70, 71]:
     ```cmd
     whois openai.com
     ```
   * Resolve DNS records[cite: 70, 73]:
     ```cmd
     nslookup openai.com
     ```
2. **Active Detection & Device Intelligence:**
   * Check local configuration[cite: 69, 74]:
     ```cmd
     ipconfig
     ```
   * Verify reachability[cite: 70, 73]:
     ```cmd
     ping openai.com
     ```
   * Trace route hops[cite: 70, 74]:
     ```cmd
     tracert openai.com
     ```
   * Check active connections[cite: 70, 74]:
     ```cmd
     netstat -an
     ```
   * Scan target open ports[cite: 70, 75]:
     ```cmd
     nmap 104.18.33.45
     ```
3. **Trust Verification & Email Authentication:**
   * Analyze email headers in PhishTool to verify SPF, DKIM, and DMARC records[cite: 70, 75].
